# Mudanças

Aqui entra o que obriga mais de um repositório. ADR que vale só para o backend fica no [airtestto-docs](https://wmreis-labs.github.io/airtestto-docs/mudancas/). ADR ou design doc que vale só para um front fica no site daquele front.

| Tipo | Pergunta |
| --- | --- |
| [RFC](rfc/index.md) | O que estamos propondo, e quais alternativas existem? |
| [ADR](adr/index.md) | O que foi decidido, e por quê? |
| [PRD](prd/index.md) | Qual problema de produto vamos resolver, e o que fica de fora? |

O design doc não mora aqui. Ele fica no repositório que vai implementar: serviço ou interface.

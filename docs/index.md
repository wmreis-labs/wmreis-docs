# Documentação da organização

Uma demanda que muda o backend e um front é registrada aqui uma vez. O desenho do serviço fica no manual do backend. O desenho da tela fica no site daquela interface.

| Site | O que guarda |
| --- | --- |
| [wmreis-docs](https://wmreis-labs.github.io/wmreis-docs/) | PRD, RFC e ADR que valem para mais de um repositório |
| [airtestto-docs](https://wmreis-labs.github.io/airtestto-docs/) | Manual do backend e design doc do que muda em `packages/` |
| [admin-docs](https://wmreis-labs.github.io/admin-docs/) | Manual do admin e design doc só daquela tela |
| [hostto-docs](https://wmreis-labs.github.io/hostto-docs/) | Manual do Hostto |
| [hostto-app-docs](https://wmreis-labs.github.io/hostto-app-docs/) | Manual do Hostto App |
| [zesalgados-docs](https://wmreis-labs.github.io/zesalgados-docs/) | Manual do Zé Salgados e ADR só dessa interface |
| [zesalgados-app-docs](https://wmreis-labs.github.io/zesalgados-app-docs/) | Manual do app do Zé Salgados |

A demanda em curso está em [Mudanças](mudancas/index.md).
